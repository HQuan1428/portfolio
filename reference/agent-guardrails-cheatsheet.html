Bảng Quy Tắc Giao Việc Cho AI Agent (Agent Guardrails)

Bản tóm tắt cô đọng sẵn sàng copy & paste vào System Prompt hoặc nhiệm vụ cho bất kỳ AI Coding Agent nào (Claude Code, Antigravity, Cursor...) khi làm việc trong dự án này.

1. Đoạn Chỉ Thị Cốt Lõi (Core Agent Directives)

Hãy sao chép đoạn dưới đây vào mỗi yêu cầu lớn gửi cho Agent:

# AGENT CONSTRAINTS CHO DỰ ÁN PORTFOLIO:
1. NGUYÊN TẮC TỐI GIẢN (PONYTAIL ULTRA):
   - Mặc định chọn giải pháp native của trình duyệt thay vì cài thư viện ngoài.
   - Không được tự ý `npm install` bất kỳ package nào ngoài Astro và @astrojs/sitemap.

2. KIẾN TRÚC & FRAMEWORK:
   - Sử dụng Astro 7 ở chế độ tĩnh (`output: 'static'`).
   - Mặc định ship 0 KB JavaScript xuống client. Tuyệt đối không thêm `client:load` hay tạo React/JSX component trừ khi được yêu cầu rõ ràng.

3. STYLING (PLAIN MODERN CSS):
   - Không dùng Tailwind CSS.
   - Sử dụng CSS Nesting native và scoped styles trong thẻ <style> của component.
   - Mọi màu sắc phải dùng biến tokens trong `src/styles/global.css` và hàm `light-dark()`.

4. ANIMATION & MOTION:
   - 100% CSS native: `@starting-style` cho Hero, `@view-transition` cho chuyển trang, `animation-timeline: view()` cho scroll reveal.
   - Tuyệt đối không cài GSAP, Framer Motion hay Lenis.
   - Chỉ animate thuộc tính `opacity` và `translate`. Bọc toàn bộ trong `@media (prefers-reduced-motion: no-preference)`.

5. DATA & NỘI DUNG:
   - Case studies đặt trong `src/content/projects/*.md` và tuân thủ schema Zod trong `src/content.config.ts`.
   - Hiển thị hình ảnh bằng component `<Image />` từ `astro:assets` với `fetchpriority="high"` cho ảnh Hero và không lazy-load ảnh trên màn hình đầu tiên.

2. Checklist Nghiệm Thu Code Của Agent (Review Checklist)

  • [ ] git status / package.json: Không xuất hiện dependency mới nào.
  • [ ] dist/: Không sinh ra file JS nào trong luồng đọc trang bình thường.
  • [ ] CSS: Không animate width, height, top, left, margin.
  • [ ] Accessibility: Các nút icon mạng xã hội ≥ 24×24px, có aria-label.
  • [ ] Colors: Màu chữ --muted đạt tương phản ≥ 4.5:1 so với --bg ở cả Light và Dark mode.
