Tổng Quan Tech Stack Dự Án Portfolio

Bản tóm tắt cô đọng các quyết định kiến trúc, tiêu chuẩn công nghệ và lý do lựa chọn trong dự án.

1. Các Trụ Cột Công Nghệ Chính

Thành phần Lựa chọn Lý do & Lợi ích cốt lõi
Framework Astro 7 (SSG) Mặc định gửi 0 KB JS; content collections có schema an toàn; tối ưu hóa ảnh tự động; build siêu nhanh với Rust/Vite 8.
Styling Plain Modern CSS Không phụ thuộc Tailwind; dùng CSS Nesting (Baseline), light-dark() cho dark mode, CSS custom properties tự nhiên.
Animation Native Browser CSS @starting-style (Hero), @view-transition (chuyển trang), animation-timeline: view() (scroll reveal); không cần thư viện JS.
Hosting Cloudflare Workers / Pages Miễn phí và không giới hạn request cho static assets; hỗ trợ custom domain; không giới hạn phi thương mại như Vercel Hobby.

2. Chỉ Số Mục Tiêu (Web Standards)

  • Core Web Vitals: LCP ≤ 2.5s, INP ≤ 200ms, CLS ≤ 0.1 (đo ở phân vị 75).
  • Accessibility (WCAG 2.2 AA): Độ tương phản chữ ≥ 4.5:1; vùng bấm ≥ 24×24px; hỗ trợ đầy đủ prefers-reduced-motion.
  • JavaScript Payload: 0 KB JS cho luồng đọc nội dung mặc định.

3. Ma Trận Quyết Định: Chọn gì & Bỏ gì?

Công nghệ cân nhắc Trạng thái Lý do quyết định
Next.js 16 Bỏ qua Quá nặng cho site tĩnh; static export làm mất image optimization mặc định; luôn đính kèm React runtime.
Tailwind CSS Bỏ qua Thêm build step và lớp trừu tượng; CSS native hiện đại (nesting, variables, light-dark) đã đáp ứng đủ và gọn gàng hơn.
GSAP / Motion Bỏ qua Thêm từ 18–35 kB bundle; CSS native hiện đại đã xử lý mượt mà chuyển trang và hiệu ứng cuộn ngoài main thread.
