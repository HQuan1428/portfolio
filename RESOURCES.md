# Portfolio Tech Stack Resources

## Knowledge

- [Astro Documentation: Why Astro & Islands Architecture](https://docs.astro.build/en/concepts/why-astro/)
  Tài liệu cốt lõi giải thích triết lý Zero-JS by default và Islands Architecture. Use for: hiểu kiến trúc SSG và quản lý component client-side.
- [Astro Content Collections Guide](https://docs.astro.build/en/guides/content-collections/)
  Hướng dẫn chính thức về quản lý nội dung Markdown với schema Zod an toàn kiểu dữ liệu. Use for: xây dựng case studies projects.
- [MDN Web Docs: @starting-style](https://developer.mozilla.org/en-US/docs/Web/CSS/@starting-style)
  Tài liệu chuẩn về CSS Transitions khi phần tử vừa xuất hiện trong DOM (Baseline Newly Available). Use for: hiệu ứng hero reveal.
- [MDN Web Docs: View Transition API](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API)
  Tài liệu chuẩn về chuyển trang mượt mà giữa các trang (Cross-document View Transitions). Use for: chuyển cảnh giữa trang chủ và trang chi tiết project.
- [Chrome for Developers: Scroll-driven Animations](https://developer.chrome.com/docs/css-ui/scroll-driven-animations)
  Tài liệu kỹ thuật về `animation-timeline: view()` không chạy trên main-thread. Use for: hiệu ứng fade-in khi cuộn trang.
- [web.dev: Core Web Vitals](https://web.dev/articles/vitals)
  Tiêu chuẩn đo lường trải nghiệm người dùng (LCP, INP, CLS). Use for: kiểm thử hiệu năng trang web.
- [W3C WCAG 2.2 Guidelines](https://www.w3.org/WAI/standards-guidelines/wcag/new-in-22/)
  Chuẩn tiếp cận web quốc tế. Use for: đảm bảo độ tương phản màu, kích thước mục tiêu bấm và prefers-reduced-motion.
- [Cloudflare Workers Static Assets Documentation](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/)
  Hướng dẫn triển khai static assets miễn phí, không giới hạn request trên Cloudflare edge network. Use for: deploy production.

## Wisdom (Communities)

- [Astro Official Discord Community](https://astro.build/chat)
  Cộng đồng chính thức của Astro, rất năng động và phản hồi nhanh cho các vấn đề về Astro 7 và SSG. Use for: hỏi đáp kỹ thuật và cập nhật thay đổi mới nhất.
- [r/webdev (Reddit)](https://reddit.com/r/webdev)
  Diễn đàn thảo luận công nghệ web toàn cầu, có nhiều bài review thực tế về portfolio và kiến trúc SSG. Use for: tham khảo kinh nghiệm và nhận feedback.
