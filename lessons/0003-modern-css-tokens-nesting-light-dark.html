Modern Plain CSS: Tokens, Nesting & light-dark()

Khai thác sức mạnh của CSS hiện đại đã đạt chuẩn Baseline: Xây dựng hệ thống giao diện tinh gọn, hỗ trợ Dark Mode tự động 100% không dùng JavaScript và không cần Tailwind.

Mục tiêu kiểm soát Agent: AI Agent rất thích cài Tailwind CSS theo thói quen mặc định. Khi hiểu rõ CSS hiện đại đã đủ mạnh, bạn sẽ dễ dàng ra lệnh cho agent dùng CSS thuần, giữ cho codebase sạch sẽ và không phụ thuộc công cụ ngoài.

1. Vì Sao Dự Án Chọn Plain Modern CSS Thay Vì Tailwind?

Tailwind giải quyết bài toán đặt tên class và CSS trùng lặp cho các dự án lớn từ năm 2018. Tuy nhiên, ở năm 2026, nền tảng web đã thay đổi:

  • Không thêm Dependency & Build step: Không cần cài đặt @tailwindcss/vite hay lo lắng về các phiên bản đột phá (breaking changes) giữa v3 và v4.
  • Astro đã có sẵn Scoped CSS: Mọi thẻ <style> viết bên trong file .astro đều được tự động gắn mã hash cục bộ. Bạn có thể đặt tên class ngắn gọn như .hero, .card mà không lo xung đột với các trang khác.
  • Dễ đọc và bảo trì: File HTML không bị tràn ngập bởi hàng chục utility classes khó đọc (như flex flex-col md:flex-row items-center justify-between p-4 dark:bg-zinc-900).

2. CSS Nesting: Viết Lồng Tự Nhiên Không Cần Preprocessor

Tính năng CSS Nesting hiện đã đạt chuẩn Baseline Widely Available (mọi trình duyệt phổ biến đều hỗ trợ natively):

/* global.css hoặc trong <style> của component */
.card {
  background: var(--bg);
  border: 1px solid var(--border);
  padding: 1.5rem;

  /* Lồng thẻ con trực tiếp */
  & h3 {
    font-size: 1.25rem;
    margin-bottom: 0.5rem;
  }

  /* Lồng trạng thái hover / focus */
  &:hover {
    border-color: var(--accent);
  }
}

Bạn không cần SASS, PostCSS hay bất kỳ plugin nào. Trình duyệt tự parse cú pháp này một cách tối ưu.

3. Hệ Thống Design Tokens Với CSS Custom Properties

Toàn bộ thiết kế nhất quán của trang web được quản lý tập trung tại src/styles/global.css qua các biến --token:

:root {
  /* Spacing Scale (Hệ quy chuẩn 4px/8px) */
  --space-xs: 0.25rem;  /* 4px */
  --space-sm: 0.5rem;   /* 8px */
  --space-md: 1rem;     /* 16px */
  --space-lg: 2rem;     /* 32px */

  /* Typography Scale */
  --font-base: 1rem;
  --font-lg: 1.25rem;
  --font-xl: 2rem;

  /* Transition Easing (Chuẩn Material Design 3) */
  --ease-out: cubic-bezier(0.05, 0.7, 0.1, 1);
  --dur-fast: 150ms;
}

4. Đột Phá Dark Mode Với Hàm light-dark()

Thông thường, các dự án dùng Tailwind hay React phải cài thư viện, viết JavaScript kiểm tra theme, lưu vào localStorage và thêm class .dark vào thẻ <html>. Nếu JavaScript bị trễ, người dùng sẽ bị hiện tượng chớp sáng (flash of unstyled theme).

Với chuẩn light-dark() (Baseline 2024), dark mode trở nên kỳ diệu:

:root {
  /* Bắt buộc: Khai báo trang web hỗ trợ cả 2 chế độ */
  color-scheme: light dark;

  /* Cú pháp: light-dark(giá_trị_sáng, giá_trị_tối) */
  --bg: light-dark(#fafafa, #0b0b0c);
  --fg: light-dark(#18181b, #ededed);
  --muted: light-dark(#52525b, #a1a1aa);
  --accent: light-dark(#2563eb, #60a5fa);
}

body {
  background-color: var(--bg);
  color: var(--fg);
}

Cơ chế: Trình duyệt tự động nhận biết hệ điều hành người dùng đang ở chế độ Sáng hay Tối và chọn đúng giá trị màu tương ứng. Không cần 1 dòng JavaScript nào, không chớp màn hình, hiệu năng 0ms latency.
