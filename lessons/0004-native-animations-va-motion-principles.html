Native Browser Animations & Motion Principles

Tạo hiệu ứng chuyển động đẳng cấp, mượt mà ngoài main thread bằng 100% CSS native: @starting-style, Cross-document View Transitions, Scroll-driven animations và chuẩn tiếp cận WCAG.

Mục tiêu kiểm soát Agent: AI Agent thường có phản xạ tự động cài đặt các thư viện nặng như GSAP, Motion hoặc Lenis (thêm từ 20–40 kB JS). Nắm vững bài này giúp bạn chỉ thị cho Agent thực hiện toàn bộ chuyển động bằng CSS native với hiệu năng 60–120 FPS.

1. Vì Sao Nói "Không" Với Thư Viện Animation JavaScript?

Tiêu chí Thư viện JS (GSAP, Framer Motion) Native Browser CSS (Dự án chọn)
Dung lượng Bundle Thêm 18–35 kB JavaScript tải qua mạng. 0 kB JavaScript (tận dụng engine sẵn có của trình duyệt).
Luồng xử lý (Threading) Chạy trên Main Thread. Khi trình duyệt bận parse dữ liệu, animation sẽ bị giật khung hình. Chạy trực tiếp trên Compositor Thread (GPU), luôn mượt mà 60–120 FPS kể cả khi main thread bận rộn.
Trải nghiệm Cuộn Lenis can thiệp vào cuộn (scroll-jacking), dễ gây khó chịu tiền đình (vestibular trigger). Giữ nguyên cuộn native của hệ điều hành, mượt mà và tôn trọng người dùng.

2. Ba Vũ Khí Animation Native Trọng Yếu

A. Hero Reveal Với @starting-style (Baseline Newly Available)

Trước đây, muốn một phần tử fade-in khi trang vừa tải, dev phải dùng JavaScript hoặc @keyframes phức tạp. Nay CSS Transition đã hỗ trợ trạng thái khởi tạo:

/* Phần tử Hero tự động trượt lên và hiện rõ khi xuất hiện trong DOM */
.hero > * {
  transition: opacity var(--dur-med) var(--ease-out),
              translate var(--dur-med) var(--ease-out);

  /* Trạng thái bắt đầu trước khi render: mờ đục và dịch xuống 16px */
  @starting-style {
    opacity: 0;
    translate: 0 16px;
  }
}

.hero > :nth-child(2) { transition-delay: 80ms; }
.hero > :nth-child(3) { transition-delay: 160ms; }

B. Chuyển Trang Mượt Mà Với Cross-Document View Transitions

Không cần SPA hay React Router, chỉ cần một dòng CSS trong global.css ở cả trang nguồn và trang đích:

@view-transition {
  navigation: auto;
}

Khi người dùng bấm vào link dự án, trình duyệt tự động chụp ảnh trang cũ và tạo hiệu ứng hòa tan (cross-fade) sang trang mới. Đặc biệt, bạn có thể tạo hiệu ứng Shared Element Transition (ảnh thumbnail ở trang chủ biến hình thành ảnh hero ở trang chi tiết) chỉ bằng cách đặt cùng một view-transition-name:

<!-- Card ở index.astro -->
<Image src={p.cover} style={`view-transition-name: cover-${p.id}`} />

<!-- Hero ở projects/[slug].astro -->
<Image src={entry.cover} style={`view-transition-name: cover-${entry.id}`} />

C. Cuộn Tới Đâu Hiện Tới Đó: Scroll-Driven Animations

Thay vì viết sự kiện window.addEventListener('scroll', ...) làm nặng máy, dùng thuộc tính animation-timeline: view():

/* Progressive Enhancement: Chỉ áp dụng nếu trình duyệt hỗ trợ */
@supports (animation-timeline: view()) {
  .reveal {
    animation: reveal-fade linear both;
    animation-timeline: view();
    animation-range: entry 10% cover 30%;
  }

  @keyframes reveal-fade {
    from {
      opacity: 0;
      translate: 0 24px;
    }
    to {
      opacity: 1;
      translate: 0 0;
    }
  }
}

Chiến lược Progressive Enhancement: Tính năng này hiện có trên Chrome/Edge/Safari (Firefox đang trong tiến trình hoàn thiện). Bọc trong @supports đảm bảo trên Firefox trang web vẫn hiển thị đầy đủ 100% nội dung bình thường mà không hề có lỗi.

3. Quy Chuẩn Chuyển Động Chuyên Nghiệp (Motion Tokens & WCAG)

  • Quy tắc GPU Only: Chỉ animate hai thuộc tính duy nhất: opacity và transform (hoặc translate). Tuyệt đối không bao giờ animate width, height, top, left, margin vì chúng kích hoạt tính toán lại layout (reflow) làm giật lag và tăng điểm lỗi CLS.
  • Thời lượng (Duration): Giữ từ 150ms – 400ms. Animation trong portfolio chỉ để định hướng mắt người nhìn, không bắt nhà tuyển dụng phải ngồi chờ đợi.
  • Chuẩn Tiếp Cận (WCAG 2.3.3): Toàn bộ hiệu ứng phải được bọc trong bộ lọc tôn trọng người dùng: 
    @media (prefers-reduced-motion: no-preference) {
  /* Toàn bộ animation chỉ kích hoạt ở đây */
}

4. Nguyên Tắc Điều Khiển Agent Cho Module Này

Chỉ thị cho AI Agent:
1. "Tuyệt đối không cài GSAP, Framer Motion hay Lenis. Toàn bộ hiệu ứng chuyển động phải sử dụng 100% CSS native."
2. "Chỉ được animate hai thuộc tính: opacity và translate. Không animate kích thước hoặc khoảng cách làm giật layout."
3. "Mọi animation phải nằm trong @media (prefers-reduced-motion: no-preference) và các tính năng scroll-timeline phải bọc trong @supports."
