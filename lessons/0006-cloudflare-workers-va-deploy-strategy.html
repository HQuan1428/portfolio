Cloudflare Workers Static Assets & Chiến Lược Triển Khai

Hiểu rõ hạ tầng phân phối nội dung tĩnh toàn cầu, miễn phí vĩnh viễn, không giới hạn lưu lượng truy cập và an toàn pháp lý cho portfolio cá nhân.

Mục tiêu kiểm soát Agent: AI Agent thường tự ý cài các adapter máy chủ nặng nề (như @astrojs/node) hoặc hướng dẫn deploy lên các nền tảng có rủi ro điều khoản. Bài học này giúp bạn giữ vững kiến trúc static thuần túy khi chỉ đạo agent.

1. Vì Sao Chọn Cloudflare Thay Vì Vercel Hay Netlify?

Nền tảng Chính sách gói miễn phí (Free Tier) Đánh giá cho Portfolio cá nhân
Cloudflare Workers / Pages Miễn phí và không giới hạn request tới static assets; hỗ trợ custom domain kèm SSL tự động toàn cầu. Lựa chọn tối ưu: Tốc độ Edge CDN cực nhanh, không lo bị khóa tài khoản vì quá tải truy cập.
Vercel Hobby Giới hạn nghiêm ngặt: "non-commercial, personal use only". Rủi ro: Nếu bạn để portfolio nhận dự án freelance hoặc kinh doanh, bạn có nguy cơ vi phạm điều khoản gói cá nhân.
Netlify Free Hệ thống tín chỉ hạn mức: 300 credits/tháng (mỗi lần deploy và dung lượng đều trừ điểm). Hạn chế: Có thể cạn kiệt credit nhanh chóng nếu bạn deploy liên tục nhiều lần trong tháng.

Bối cảnh công nghệ: Vào tháng 1/2026, đội ngũ phát triển Astro chính thức gia nhập Cloudflare. Astro vẫn là mã nguồn mở 100% nhưng được tích hợp hoàn hảo nhất với hạ tầng Cloudflare.

2. Mô Hình Xuất Tĩnh (Static Output)

Trong file cấu hình astro.config.mjs, chế độ mặc định của Astro là output: 'static':

import { defineConfig } from 'astro/config';
import sitemap from '@astrojs/sitemap';

export default defineConfig({
  site: 'https://tenban.dev', // Bắt buộc khai báo để sinh sitemap và canonical URL chuẩn
  integrations: [sitemap()],
});

Khi bạn chạy lệnh:

npm run build

Astro đọc toàn bộ component và Markdown, biên dịch ra thư mục dist/ gồm toàn các file HTML, CSS và hình ảnh tĩnh WebP. Thư mục này có thể đặt lên bất kỳ máy chủ CDN nào trên thế giới mà không cần Node.js chạy ngầm.

3. Quy Trình Triển Khai Lên Cloudflare

Có hai cách triển khai cực kỳ đơn giản và nhanh chóng:

  1. Kết nối Git (Khuyên dùng): Đẩy code lên GitHub. Trong Cloudflare Dashboard, kết nối với kho lưu trữ. Cloudflare sẽ tự động build và deploy mỗi khi bạn push code mới.
  2. Dùng công cụ dòng lệnh (Wrangler): 
    npx wrangler deploy

4. Nguyên Tắc Điều Khiển Agent Cho Module Này

Chỉ thị cho AI Agent:
1. "Giữ nguyên cấu hình mặc định output: 'static' trong astro.config.mjs. Tuyệt đối không cài thêm bất kỳ SSR adapter nào (như @astrojs/node hay @astrojs/vercel)."
2. "Luôn khai báo đúng thuộc tính site với tên miền chính thức trong file cấu hình Astro."
3. "Trước khi triển khai, luôn chạy lệnh npm run build và kiểm tra thư mục dist/ đảm bảo không có file JavaScript thừa."
