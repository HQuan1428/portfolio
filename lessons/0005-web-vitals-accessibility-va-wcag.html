Bài học 0005 • Chất Lượng & Chuẩn Quốc Tế

Core Web Vitals, SEO & Chuẩn Tiếp Cận WCAG 2.2 AA

Nắm vững các chỉ số đo lường trải nghiệm người dùng hiện đại, tối ưu SEO tĩnh và biến portfolio thành một sản phẩm công nghệ hoàn hảo đáp ứng chuẩn quốc tế.

Mục tiêu kiểm soát Agent: Nhà tuyển dụng cấp cao và các chuyên gia frontend đánh giá ứng viên qua chi tiết: tốc độ tải, độ mượt khi bấm phím Tab, và độ tương phản màu. Biết các tiêu chuẩn này giúp bạn thẩm định chính xác chất lượng code mà AI Agent tạo ra.

1. Bộ Ba Chỉ Số Core Web Vitals (Google & Web.dev)

Google đo lường hiệu năng thực tế của trang web ở phân vị thứ 75 (75th percentile) qua 3 chỉ số cốt lõi:

Chỉ số Mục tiêu chuẩn Cách kiến trúc dự án của chúng ta đáp ứng
LCP
(Largest Contentful Paint)		 ≤ 2.5 giây
(Thời gian phần tử nội dung lớn nhất hiện lên)		 Astro xuất sẵn HTML tĩnh. Quy tắc vàng: Không bao giờ đặt loading="lazy" cho ảnh Hero; dùng fetchpriority="high" để tải ngay lập tức.
INP
(Interaction to Next Paint)		 ≤ 200 mili-giây
(Độ trễ phản hồi khi người dùng bấm/tương tác)		 Astro ship 0 KB JS mặc định. Main Thread hoàn toàn rảnh rỗi, người dùng bấm vào là trang phản hồi tức thì (INP thực tế thường < 20ms).
CLS
(Cumulative Layout Shift)		 ≤ 0.1
(Độ dịch chuyển giật cục của giao diện)		 Sử dụng component <Image /> từ astro:assets để luôn tự động tính sẵn width và height, loại bỏ 100% hiện tượng giật trang khi ảnh tải xong.

2. Chuẩn Tiếp Cận WCAG 2.2 AA: Chi Tiết Đắt Giá Của Senior Dev

Một trang web portfolio chuyên nghiệp phải dùng được cho mọi người dùng, kể cả người khiếm thị hay người dùng bàn phím:

A. Độ Tương Phản Màu (SC 1.4.3 & 1.4.11)

  • Chữ thường so với nền: Tỷ lệ tương phản tối thiểu 4.5 : 1.
  • Chữ lớn (trên 24px) và các thành phần đồ họa/đường viền: Tối thiểu 3.0 : 1.
  • Lưu ý: Phải kiểm tra độ tương phản ở cả hai chế độ Light Mode và Dark Mode.

B. Kích Thước Vùng Bấm (Target Size - Mới Trong WCAG 2.2, SC 2.5.8)

Các nút bấm, link icon (GitHub, LinkedIn, Resume PDF) trên điện thoại cảm ứng phải có kích thước tối thiểu 24 × 24 CSS pixels để ngón tay dễ dàng bấm trúng mà không bị bấm nhầm.

C. Chống Che Khuất Vết Focus (Focus Not Obscured - SC 2.4.11)

Khi người dùng duyệt web bằng phím Tab, nếu trang web có Sticky Header cố định ở đầu trang, vết focus không được bị header che mất. Giải pháp chuẩn CSS cực kỳ đơn giản:

/* global.css */
html {
  /* Dự phòng khoảng trống 5rem để header không che mất phần tử được focus */
  scroll-padding-top: 5rem;
}

:focus-visible {
  /* Vết viền focus rõ ràng, nổi bật */
  outline: 2px solid var(--accent);
  outline-offset: 3px;
}

3. SEO Tĩnh Chuẩn Mực & Open Graph

Một layout chuẩn (src/layouts/Base.astro) cần bao gồm đầy đủ:

  • Semantic HTML: Cấu trúc rõ ràng <header>, <nav>, <main>, <footer>; đúng thứ tự thẻ <h1> → <h2> → <h3>.
  • Open Graph Tags: Cung cấp og:title, og:description, og:image (ảnh kích thước 1200×630px) để hiển thị bản xem trước đẹp mắt khi dán link trên mạng xã hội.
  • Sitemap tự động: Tích hợp @astrojs/sitemap tự động sinh file sitemap-index.xml mỗi khi build dự án.

4. Nguyên Tắc Điều Khiển Agent Cho Module Này

Chỉ thị cho AI Agent:
1. "Không được đặt loading='lazy' trên ảnh đại diện Hero; bắt buộc dùng fetchpriority='high'."
2. "Mọi icon liên kết mạng xã hội hoặc nút bấm phải có kích thước tối thiểu 24x24px và có thuộc tính aria-label rõ ràng."
3. "Đảm bảo mã màu chữ biến --muted có tỷ lệ tương phản tối thiểu 4.5:1 so với biến --bg ở cả hai chế độ màu."
